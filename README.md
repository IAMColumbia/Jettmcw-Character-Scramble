# Character Scramble

A competitive local multiplayer game where players scramble to pick the good characters.

## Description

Have you ever tried playing a game with your friends, only to get stuck in the **character select screen**?
With just **too many choices**, **too many layers**, and **controls that make no sense**?

**That's what this game was made to capture.**

So, stumble over your friends, race to figure out what the controls are **(they change every round)**, and try to get the most points by making the best combos.
